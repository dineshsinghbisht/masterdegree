Exercise 4. Normalization and Standardization¶

Deep learning neural networks learn how to map inputs to outputs from examples in a training dataset. The purpose of exercise is to compare results of MLP prediction with raw, normalized and standardized input data.

# Fit model: epoch = 100

raw_histories = []   # loss history of each run (for plotting)
raw_train_mse = []   # train MSE of each run
raw_test_mse = []    # test MSE of each run

for run in range(5):
    keras.utils.set_random_seed(run)   # seeds 0-4; use the same in every section

    # Build a fresh model for each run
    inputs = Input(shape=(X_train.shape[1],))
    x = Dense(25, activation='relu', kernel_initializer='he_uniform')(inputs)
    outputs = Dense(1, activation='linear')(x)
    model = Model(inputs=inputs, outputs=outputs)
    model.compile(loss='mean_squared_error', optimizer=SGD(learning_rate=0.01, momentum=0.9))

    # Train on raw data
    history = model.fit(X_train, y_train, validation_data=(X_test, y_test), epochs=100, verbose=0)

    # Save the results of this run
    raw_histories.append(history)
    raw_train_mse.append(model.evaluate(X_train, y_train, verbose=0))
    raw_test_mse.append(model.evaluate(X_test, y_test, verbose=0))

Write conclusion:

Differences between raw, normalized and standardized data¶

Raw data: The values are used exactly as they are, so features and targets can have very different sizes. Large values give large errors and large weight updates, which can make the training unstable, so training model would be harder and may not work as well.

Normalized data: The values are rescaled to a fixed range from 0 to 1. This makes all the values small and similar in size, so the training is more stable. It works best when the data has clear limits and no extreme outliers.

Standardized data: The values are shifted and rescaled so that the average is 0 and the spread (standard deviation) is 1. This also keeps the values small and similar in size, and it works well for bell-shaped data and data with outliers.

What did I learn in this exercise?¶

  1. Neural networks work better with scaled numbers. Without scaling, variables with large numerical values can dominate the learning process and negatively affect the optimization of the model.
  2. In regression problems, the target may need scaling too. In this exercise the inputs were already small, and the problem was the large target y. Scaling only X gave nan or a model that did not learn at all.
  3. Scalers are fitted on the training data only, and then applied to the test data. This wa the model does not see the test data before testing.
  4. Scaling the target also changes how MSE is measured. Since normalization and standardization scale the values differently, their MSE scores aren’t directly comparable. I converted the predictions back to the original scale first so I could compare them fairly.
  5. Repeating each experiment 5 times shows how much the results change because of random starting weights.
  6. Loss curves show if the model is learning. An empty plot means the loss became nan.

Did I have difficulties in the exercise?¶

Yes. At first I did not understand why the MSE was nan, I wondered if I did something wrong. Later I got to know it was because of the large target values. It was also confusing that the scaled MSE of normalization looked much better than standardization, until I converted the predictions back to the original units and saw the opposite.
