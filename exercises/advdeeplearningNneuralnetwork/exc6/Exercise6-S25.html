# MLP for regression
import tensorflow as tf
from sklearn.datasets import make_regression
from sklearn.preprocessing import StandardScaler
from keras.models import Sequential
from keras.layers import Dense
from keras.optimizers import SGD
from matplotlib import pyplot

# Generate regression dataset
X, y = make_regression(n_samples=2000, n_features=20, noise=0.1, random_state=1) #default target = 1
# standardize dataset
X = StandardScaler().fit_transform(X)
y = StandardScaler().fit_transform(y.reshape(len(y),1))[:,0]

# split into train and test
n_train = 1000 #50/50
trainX, testX = X[:n_train, :], X[n_train:, :]
trainy, testy = y[:n_train], y[n_train:]

Conclusion¶

NOTE: Conclusion is one evaluation criterion for the exercise, so pay attention to writing them

Write summary of results

In this exercise I trained the same simple MLP (20 inputs, 25 hidden nodes, 1 output) on the same regression data with three different loss functions MSE, MAE and Huber. The optimizer, the number of epochs (100) and the starting weights (same random seed) were the same, so the only difference was the loss function.

Results¶

Loss Train Test
MSE 0.001 0.001
MAE 0.024 0.024
Huber 0.001 0.002
  • All three losses learned the task. The loss started high and dropped quickly in the first few epochs. For comparison, a model that always predicts the average would have an MSE of about 1.0.
  • None of the models overfitted. In all three plots the train and test curves are almost on top of each other, and the final values are very close.
  • MSE and Huber gave smooth curves. MAE was noisier and did not settle as smoothly, probably because its gradient stays the same size when the error becomes small.
  • The loss values cannot be compared directly as numbers, because each loss measures the error in a different way. For example, MAE looks larger than MSE, but that does not mean its predictions are worse.

What I learned¶

The loss function defines what the model tries to minimize, so it changes how the training behaves. On this dataset the data is clean and has almost no outliers, so the advantage of MAE and Huber for outliers was not visible, and MSE worked well. With data that has outliers, MAE or Huber could be the better choice. I also learned that the starting weights change the results a little, so I fixed the random seed to compare the losses fairly.
